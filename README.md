# WallpaperShell · 0.2.0

WallpaperShell — приложение живых обоев для Windows x64 на C# / WinForms / WebView2. **Paper Green**, **Luna Blue** и **Classic** — темы внутри приложения.

Перед публикацией проведена проверка безопасности и очистка личных настроек: [отчёт](docs/SECURITY_REVIEW.md), [локальные данные и подключения](docs/PRIVACY.md), [сообщение об уязвимости](SECURITY.md). В новой установке погода и EcoFlow выключены до явной настройки; часовой пояс берётся из системы.

Luna Blue сочетает жидкий синий мрамор, отдельный полумесяц и стеклянные виджеты. Вода реагирует на мышь, Луна — на системный звук. В покое вода прекращает перерисовку; звук обрабатывается в памяти для визуализации, без записи и микрофона.

## Запуск

Распакуй весь portable ZIP в собственную доступную для записи папку на локальном диске с Windows ACL. Для ключа создаётся защищённый data/private; сетевые папки и файловые системы без Windows ACL не подходят. Запускай RUN.cmd для обычного окна, RUN_DESKTOP.cmd для рабочего стола или RUN_LUNA_BLUE.cmd для Luna Blue. Не переноси один EXE отдельно от папки. Исполняемый файл приложения: bin/WallpaperShell.exe.

Нужны Windows x64, .NET Framework 4.8 и Microsoft Edge WebView2 Runtime. Node.js и SDK-библиотеки WebView2 входят в portable пакет; отдельно устанавливать Node или npm не нужно. Сам WebView2 Runtime устанавливается отдельно. Приложение не устанавливает автозапуск или службу.

«Рабочий стол» возвращает значки Windows и завершает WallpaperShell. Обычное закрытие завершает только собственные окна и backend. Существующие обои и их службы приложение не заменяет.

## Настройки и виджеты

В общем окне настроек находятся оформление, режим приложения, выбор устройств и конструктор. Компоновки каждой темы сохраняются отдельно. В редакторе можно перемещать, масштабировать и скрывать блоки; есть магнитное выравнивание, отмена, повтор и перенос раскладки через JSON.

Часы, календарь, погода, память, интернет, заряд мыши, плеер, открытые окна, уведомления и категории используют системные источники. Недоступные измерения показываются как прочерк. Заряд поддерживается только для устройств с доступной телеметрией. Уведомления требуют отдельного подключения Windows; пакет идентичности и сертификат автоматически не устанавливаются.

Настройки и раскладки хранятся в data, служебное состояние — в закрытых локальных файлах runtime/companion. Эти файлы исключены из публичного исходника и пакетов обновления. Не публикуй рабочую папку с личными данными.

## Репорт и обновления

Настройки → Общие → Приложение: **Репорт** открывает форму GitHub Issues. Пользователь сам описывает ошибку и отправляет сообщение. Приложение не прикладывает логи, окна, уведомления или аккаунты автоматически.

**Обновить** вручную проверяет последний стабильный GitHub Release. После проверки появляется отдельная кнопка загрузки и установки. Приложение проверяет SHA256 архива и содержимое пакета, затем перезапускается через собственный helper. Настройки и раскладки сохраняются. Ошибка записи вызывает восстановление заменённых файлов из резервной копии; внезапное отключение питания не покрывается автоматическим восстановлением.

Адрес проекта задаётся в app-release.json: Kodzimba/WallpaperShell. Для работы репортов и обновлений необходимо создать этот репозиторий и опубликовать первый стабильный релиз; одна подготовка локальной папки этого не делает. Секрет GitHub для чтения публичных релизов не нужен.

## Сборка и публикация

Открой WallpaperShell.csproj в Visual Studio либо выполни tools/bootstrap-build.ps1 в Windows PowerShell. Bootstrap получает закреплённую официальную версию Node.js с проверкой SHA256; сборка не зависит от соседних проектов или локального кеша разработчика. После сборки tools/test.ps1 выполняет JS и нативные проверки на тестовых данных.

tools/export-source.ps1 создаёт чистый исходник по разрешённому списку файлов и проверяет его перед публикацией. tools/package-release.ps1 создаёт WallpaperShell-win-x64.zip с манифестом и отдельным .zip.sha256. CI проверяет чистую сборку; release workflow подготавливает черновик релиза. Порядок выпуска: [docs/RELEASING.md](docs/RELEASING.md).

Публичный исходник сохраняет все три темы. Непроверенные старые растровые фоны Classic заменены проверенным мрамором Luna Blue; локальные оригиналы не публикуются. Шрифты и сторонние библиотеки сопровождаются лицензиями. Происхождение включённых ресурсов: [NOTICE.md](NOTICE.md) и licenses/assets-provenance.json.

Внутренние namespace, ключи настроек и Windows package identity PaperGreen сохранены для совместимости существующих установок; название приложения и публичного репозитория — WallpaperShell.
