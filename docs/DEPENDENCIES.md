# Dependency verification

Reviewed on 2026-10-22. This is a dated review, not a guarantee against future advisories.

- Node.js **24.22.1 LTS** is pinned to the official Windows x64 archive SHA256 and executable SHA256. It contains the fixes listed in the [2026-10-21 Node security release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases). The exact hashes are independently listed on the [official release page](https://nodejs.org/en/blog/release/v24.22.1/). Bootstrap extracts only node.exe and its license; it does not install npm packages or use Node from PATH.
- Microsoft.Web.WebView2 SDK **1.0.3800.47** is retained for API compatibility. The downloaded [official NuGet package](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3800.47) matched its recorded package SHA256. All three vendored DLLs matched the package's net462 and Windows x64 entries. Per-file hashes are enforced before build/export/packaging. A newer stable SDK exists; this review did not establish an advisory against the retained wrappers/loader and did not change the SDK API surface. The SDK does not include Chromium. The separately installed [Evergreen Runtime updates through Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/evergreen-vs-fixed-version); users must keep it updated.
- CI actions are pinned to verified full commit SHAs: [checkout v7.0.1](https://github.com/actions/checkout/releases/tag/v7.0.1), [upload-artifact v7.0.2](https://github.com/actions/upload-artifact/releases/tag/v7.0.2), [download-artifact v8.0.2](https://github.com/actions/download-artifact/releases/tag/v8.0.2). Checkout does not persist credentials. Build/test jobs have read-only repository permissions. A separate job receives write access only to prepare a draft from the validated artifact; it does not check out or execute project code. Publication remains a separate manual review.

Run `powershell.exe -NoProfile -File .\tools\assert-dependencies.ps1` to verify the local build dependencies without executing them. `tools/test-dependency-integrity.ps1` tests rejection of changed bytes, unapproved URLs and traversal-like dependency paths using inert temporary fixtures. A changed dependency requires review of its official release/advisories, license and hashes before updating `tools/runtime-dependencies.json`.

CI requires an exact existing `vX.Y.Z` tag matching `app-release.json`, including for manual workflow dispatch. It uploads only the release ZIP and checksum, never the build tree, profiles or local state. The workflow has not been run against GitHub during this local review.
